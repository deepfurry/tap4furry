# Tap4Furry — Content & Resource Policy

## Three Decisions

Always distinguish:

```text
Can the Resource be recorded?
Can a Source be listed?
Can the Resource / Source be actively distributed?
```

## Resource Eligibility

Resource relevance:

```text
Direct
Strong
Contextual
```

Do not become a generic internet encyclopedia.

## Submission

Keep submission light:

```text
Name
Type
Category
Summary or URL
Why it belongs on Tap4Furry
At least one Source where possible
```

Metadata may be enriched automatically.

## Completeness

Suggested states:

```text
Basic
Good
Rich
```

Incomplete historical resources may still be valuable.

## Duplicate Detection

Use canonical URL, domain, external IDs, normalized name, source overlap, creator/title, and tag similarity.

Do not automatically merge published Resources.

## Source Policy

Source type describes origin, not universal legality or safety.

Avoid:

```text
Safe Download
Guaranteed Legal
Verified Safe
```

Prefer factual labels such as Official Source / Creator-provided / Community-submitted / Link checked.

## No General File Hosting

Do not become a host for game archives, large asset bundles, software packages, ebooks, or arbitrary archives.

Platform-hosted media stays limited to product needs.

## Preservation vs Distribution

```text
Historical record
≠
Current source availability
≠
Active recommendation
```

## Rights / Disputes

Rights-related requests are high-priority.

Possible states:

```text
ReviewHold
RightsReview
Disputed
```

Metadata may remain while source distribution is limited.

## Content Rating

```text
General
Mature
Explicit
```

Rating is distinct from descriptive tags and may affect feature eligibility.

## Exchange

No payment, checkout, escrow, delivery confirmation, or transaction warranty.

## Discussions

Core rules:

- stay relevant;
- no flooding/spam;
- no harassment;
- no doxxing;
- no impersonation;
- no malicious links;
- respect content boundaries.

## Polls

Polls must not be used to publicly target or judge individual users.

## Translation

Keep UI language, Resource original language, supported languages, and localized Tap4Furry content separate.
